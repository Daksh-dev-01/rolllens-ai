# Demo Script — RollLens AI

Target length: 2–3 minutes.

## 1. Introduce the problem (20 seconds)

“Scanned electoral-roll PDFs are difficult to search and manually verify. RollLens AI is designed to connect structured search results to their original source evidence.”

## 2. Open Documents (25 seconds)

Show the seeded synthetic library, status badges, page counts, and sample-mode banner. Explain that these records are synthetic.

## 3. Demonstrate the upload affordance (20 seconds)

Choose a small PDF or use the drag-and-drop area. Explicitly state that in the current demo slice this is a browser-side simulation: the file is not sent to a server or processed.

## 4. Show the intended evidence workflow (40 seconds)

When Member 2's explorer is integrated, search for a synthetic record, open the source page, and show the bounding-box highlight and verification state. Do not claim the extraction is live if using mock data.

## 5. Show analytics and comparison (40 seconds)

When integrated, show a dataset-scoped aggregate chart and a comparison between synthetic versions. Explain that version differences require human review and are not proof of misconduct.

## 6. Close (15 seconds)

“RollLens is built around traceability: results should be inspectable, uncertainty should be visible, and conclusions should be grounded in source evidence.”

## Demo safety checklist

- Use synthetic or properly authorized data.
- Confirm the demo-mode indicator is visible.
- Do not show API keys, private paths, or real personal records.
- Do not describe simulated uploads or mock queries as live AI.
- Have the frontend running before the presentation begins.
